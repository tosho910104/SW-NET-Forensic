### How to Install (Portable & Ready to Go) 🚀

Good news: **SW-NET Forensic is a 100% portable application.** There is no bloated installer, and it won't leave a mess in your system registry. 

**Step 1: Download & Extract 📦**
Download the latest `.zip` archive from the official release page. Extract the contents to any folder on your drive (for example, `C:\IT-Tools\SW-NET-Forensic`).

**Step 2: Run as Administrator 🛡️**
Because this is an advanced forensic tool that reads low-level network connections and process memory, it requires elevated privileges. Simply right-click on `SW-NET-Forensic.exe` and select **Run as administrator**.

**Step 3: .NET 8 Runtime (One-time check) ⚙️**
The software is powered by the modern and secure **Microsoft .NET 8 Desktop Runtime**. 
*   **Already have it?** The application will launch instantly.
*   **Don't have it yet?** No worries! Upon the first launch, Windows will automatically prompt you with a direct, official Microsoft link to download the required runtime. It takes less than a minute to install.
